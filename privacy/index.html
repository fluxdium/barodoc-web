무료 서식 52종도장 만들기실무 계산기 6종실무 가이드

개인정보처리방침

시행일자: 2026-11-23 · 적용 서비스: 바로서식 (https://barodoc.pe.kr)

바로서식(이하 "본 사이트")는 이용자의 개인정보를 최우선으로 보호하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 서식·도장·계산기 입력 데이터(브라우저 로컬 처리), 공유 링크(#d=), 그리고 문의하기 폼 데이터(외부 폼 서비스 전달)가 각각 어떻게 처리·보관·삭제되는지 명확히 구분하여 안내합니다.

1. 서식·도장·계산기 입력 정보의 브라우저 로컬 처리 원칙

본 사이트의 52종 무료 서식 작성기, 6종 실무 계산기, 온라인 도장 및 자필 서명 도구는 별도의 회원가입이나 자체 백엔드 데이터베이스를 사용하지 않고 이용자의 웹 브라우저 내부에서만 동작합니다.

  • 서식 및 계산기에 입력하는 성명, 생년월일, 주민등록번호, 주소, 연락처, 계좌번호, 사업자등록번호, 급여·금액, 생성한 도장 및 자필 서명 이미지 등 일체의 문서·계산 데이터는 본 사이트 서버로 전송되거나 수집·저장되지 않습니다.
  • PDF 인쇄 및 PNG 이미지 변환 작업 역시 이용자의 기기 브라우저 메모리 내부에서만 처리됩니다.

2. 브라우저 로컬 저장소(localStorage · sessionStorage) 저장 항목 및 삭제 방법

이용자의 반복 입력 편의를 위해 아래 기능에 한해 이용자 본인 기기의 웹 브라우저 저장소에만 데이터를 보관합니다. 해당 데이터는 외부 서버로 전송되지 않으며 이용자가 언제든지 직접 삭제할 수 있습니다.

  • 임시 작성 내용 보관 (localStorage): 실수로 새로고침해도 작성 중인 내용이 사라지지 않도록 현재 기기 브라우저에만 임시 저장합니다. 각 서식 상단의 '초기화' 버튼을 누르거나 브라우저 사이트 데이터를 삭제하면 즉시 영구 삭제됩니다.
  • 내 개인·회사 정보 저장 (localStorage, barodoc_user_profile_v1): 이용자가 직접 '내 정보 불러오기 → ⚙ 설정'에서 저장을 선택한 경우에 한해 성명·생년월일·연락처·주소·부서·직위·계좌번호(개인 정보), 상호·사업자등록번호·대표자명·회사 연락처·사업장 주소·업태·종목·계좌번호(회사 정보), 기본 도장·서명 설정을 본인 브라우저에만 보관합니다. 상단 '⚙ 설정' 모달 하단의 '프로필 삭제' 버튼 또는 브라우저 사이트 데이터 삭제로 즉시 삭제할 수 있습니다.
  • 내 도장함 및 자필 서명 저장 (localStorage): 이용자가 직접 저장 버튼을 누른 도장 이미지와 자필 서명 이미지만 본인 브라우저에 보관됩니다. 도장함·서명함의 개별 '삭제' 버튼으로 언제든지 삭제할 수 있습니다.
  • 거래 문서 이어쓰기 임시 전달 (sessionStorage): 견적서·발주서·거래명세서·청구서·영수증 간 '이어쓰기' 버튼 클릭 시 품목·거래처 정보를 다음 페이지로 넘기기 위해 브라우저 세션 저장소에만 잠시 보관하며, 탭을 닫으면 자동 삭제됩니다.

※ PC방, 도서관 등 공용 컴퓨터에서 이용하신 경우 문서 출력을 마친 뒤 반드시 서식 '초기화', '프로필 삭제', 도장·서명 삭제 또는 브라우저 쿠키·사이트 데이터 전체 삭제를 진행하시기 바랍니다.

3. 상대방 입력 요청 공유 링크(#d=...)의 처리 방식 및 주의사항

이용자가 서식 상단의 '상대방 입력 요청 링크 복사' 기능을 사용하면, 현재 문서에 입력한 항목과 날인된 도장·서명 데이터가 압축·인코딩되어 URL 해시 프래그먼트(https://barodoc.pe.kr/.../#d=...)에 포함됩니다.

  • 서버 비전송: 웹 표준상 URL의 # 뒤쪽 프래그먼트 영역은 웹 서버로 전송되지 않으며, 본 사이트 서버에도 저장되지 않습니다.
  • 수신자 열람 범위: 해당 링크 전체를 전달받은 상대방(또는 링크에 접근한 제3자)은 링크 안에 포함된 문서 입력 정보, 도장 이미지, 자필 서명 내용을 그대로 열람하고 수정·저장할 수 있습니다.
  • 이용 시 주의사항: 주민등록번호, 계좌번호, 주소 등 민감한 개인정보가 포함된 공유 링크는 반드시 실제 거래·계약 당사자에게만 1:1 비공개 채널로 전달하시고, 공개 게시판·오픈채팅방 등에 게시하지 마시기 바랍니다.

4. 온라인 문의하기(/contact/) 폼 데이터 처리 안내 (Web3Forms)

서식 입력 데이터와 달리, 이용자가 문의하기 페이지의 온라인 문의 폼을 직접 작성해 제출하는 정보는 오류 수정 및 회신 처리를 위해 외부 폼 전달 서비스를 거쳐 운영자에게 전달됩니다.

  • 수집·전달 항목: 문의 유형(필수), 문의 내용(필수), 회신받을 이메일 주소(선택 입력).
  • 처리 목적: 서비스 오류 제보 확인, 신규 서식 요청 검토, 법령·내용 정정 반영, 제휴 문의 확인 및 이용자가 이메일을 입력한 경우 회신 발송.
  • 처리 경로 (외부 전송): 제출된 문의 데이터는 암호화된 HTTPS 통신을 통해 Web3Forms (api.web3forms.com)를 거쳐 운영자 수신 메일함으로 전달됩니다.
  • 보관 기간 및 삭제 기준: 접수된 문의 내역과 회신 이메일은 처리 및 답변 완료 후 목적 달성 시 지체 없이 파기하며, 오류 재현·정정 이력 확인이 필요한 경우에 한해 최대 1년 이내 보관 후 파기합니다. 이용자가 문의하기 페이지를 통해 이전 문의 내역의 삭제를 요청하면 본인 확인 후 즉시 삭제합니다.

5. 쿠키(Cookie) 및 제3자 광고(Google AdSense) 안내

본 사이트는 무료 서비스 운영을 위해 Google LLC가 제공하는 Google AdSense 광고 및 방문 통계 도구를 사용할 수 있습니다.

  • Google을 포함한 제3자 광고 공급업체는 이용자의 본 사이트 및 다른 웹사이트 이전 방문 기록을 바탕으로 맞춤형 광고를 게재하기 위해 쿠키를 사용할 수 있습니다.
  • Google의 광고 쿠키 사용을 통해 Google 및 파트너는 이용자의 방문 기록을 기반으로 적합한 광고를 표시합니다.
  • 이용자는 Google 광고 설정(adssettings.google.com)에서 언제든지 맞춤형 광고를 비활성화할 수 있으며, 웹 브라우저의 쿠키 차단 설정을 통해 쿠키 저장을 거부할 수 있습니다.

6. 개인정보 보호 문의처 및 권리 행사

본 사이트의 개인정보 처리, 문의 내역 열람·삭제 요청, 불만 처리 등은 아래 온라인 문의 폼을 통해 접수해 주시면 영업일 기준 1~3일 이내에 확인 후 조치하겠습니다.

  • 운영자 / 서비스명: 바로서식 운영팀
  • 접수 경로: 문의하기 페이지의 온라인 문의 폼

7. 개인정보처리방침의 변경

본 개인정보처리방침은 법령이나 서비스 기능 변경에 따라 수정될 수 있으며, 변경 시 시행일자 갱신과 함께 본 페이지를 통해 공지합니다.
